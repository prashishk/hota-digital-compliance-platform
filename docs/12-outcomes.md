# 12 — Outcomes & KPI Framework

No unsupported production metrics are claimed in this portfolio representation.

## KPI Framework

- registration completeness rate
- first-pass review rate
- average review turnaround
- clarification rate
- SLA adherence
- certification cycle time
- reviewer workload
- evidence completeness
- exception ageing

## Measurement

Establish a baseline before rollout, measure each workflow stage after implementation, and segment results by case type and period. Avoid reporting averages alone when long-tail cases materially affect service performance.
