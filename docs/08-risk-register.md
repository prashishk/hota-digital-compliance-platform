# 08 — Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Incorrect eligibility logic | Critical | controlled rule catalogue + independent validation |
| Missing evidence | High | mandatory checklist + validation |
| Reviewer overload | High | workload dashboard + SLA monitoring |
| Sensitive data exposure | Critical | minimisation + RBAC + encryption |
| AI hallucination | High | constrained inputs + human review |
| Integration failure | High | monitoring + retry/reconciliation |
| Regulatory change | High | versioned rules + change governance |
| User adoption | Medium | usability testing + training |

## Key Delivery Controls

Maintain a live RAID log and escalate risks based on **impact × likelihood × proximity**, not only severity labels.
