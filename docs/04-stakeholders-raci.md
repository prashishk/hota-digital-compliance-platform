# 04 — Stakeholders & RACI

| Stakeholder | Responsibility |
|---|---|
| Hospital / Applicant | submit information and evidence |
| Regulatory Operations | case administration and validation |
| Specialist Reviewer | technical / clinical compliance review |
| Approving Authority | accountable decision |
| Platform Team | application, integration and reliability |
| Security / Privacy | access and data controls |
| Audit / Oversight | evidence and traceability |

## High-Level RACI

| Activity | Applicant | Operations | Specialist | Approver | Platform |
|---|---|---|---|---|---|
| Registration | R | A | I | I | C |
| Evidence validation | C | A/R | C | I | C |
| Specialist assessment | I | C | A/R | I | C |
| Clarification | R | A | R | I | C |
| Final decision | I | C | C | A/R | I |
| Certification | I | R | C | A | C |
| Audit review | I | C | C | I | R/C |
